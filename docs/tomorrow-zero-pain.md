# 明天私教课 · 零痛路径

> **先读这两句**  
> 1. 腕上麦克风是 **DayTap Watch App**。不要去装系统「语音备忘录」，也不要换第三方录音机。手表上没有得到。  
> 2. 装好之后，**Track 1（不进得到）** 和 **Track 2（到了 iPhone 再进得到）** 都用同一段手表录音。表没装好就改 **Track 0**（手机录）。

装机的每一步：[`daytap-watch-app.md`](daytap-watch-app.md)。双轨说明：[`watch-two-tracks.md`](watch-two-tracks.md)。

这篇不教你写 `.md`。你只录音、出字、把文字贴给 Bot。

## 课前：在 Mac 上装进手表（大约 15 分钟）

没有 Mac 就装不上。云端仓库里没有办法直接装到手表。

| # | 做什么 | 通过了是什么样 |
|---|--------|----------------|
| 1 | Mac 上用 Xcode 打开 `apps/DayTap/DayTap.xcodeproj` | 能看到 target **DayTap** 和 **DayTap Watch App** |
| 2 | 两个 target 都选你的 Apple ID 做 Team，自动签名 | 没有红色签名错误 |
| 3 | scheme 选 **DayTap**，目的地选你的 **iPhone**（不要选模拟器），按 Run | iPhone 上出现 DayTap |
| 4 | iPhone 若提示不受信任：设置 → 通用 → VPN 与设备管理 → 信任，然后再 Run | App 能打开 |
| 5 | 手表主屏幕有 **DayTap**。没有就改 scheme 为 **DayTap Watch App**，目的地选手表，再 Run | 表上能点开 |
| 6 | 手表：允许麦克风 → **开始** → 说两句 → **停止** | 表上显示已保存 / 正在传 |
| 7 | iPhone 打开 DayTap，能看到这条，点一次 **分享** 确认分享表出得来 | 列表里有一条 m4a |
| 8 | 得到大脑在 **iPhone** 上能打开（只为 Track 2） | 手表上仍然没有得到 |

第 7 步失败：两台设备靠近，都打开 DayTap，手表点 **再传一次**。还是没有，就不要赌这节课，改文末 Track 0。

这不是 App Store 安装。商店里搜不到。免费 Apple ID 大约 7 天后要重新 Run 一次。

## 课上（手表两下）

| # | 在哪 | 点什么 |
|---|------|--------|
| 1 | **手表 DayTap** | **开始** |
| 2 | **手表 DayTap** | 下课 **停止** |

DayTap 必须留在前台。手腕放下、表盘退到后台时，它会停止并保存，然后排队传到 iPhone。它不会全天在后台一直录。来电或 Siri 打断也会停下来保存。

长课、人坐着不动：直接用 Track 0，更稳。

## 课后 Track 1 · 不进得到

| # | 在哪 | 点什么 |
|---|------|--------|
| 1 | **iPhone DayTap** | 打开刚出现的那一条 |
| 2 | **iPhone** | **分享** → 飞书妙记；或 **存到文件**；或隔空投送到 Mac 做系统转写 |
| 3 | **不要** | 不要把这条选进得到大脑 |
| 4 | **本对话** | 粘贴全文：「私教 · Track1 · 出决策卡」 |

**待验证**：停录后几秒内 iPhone 是否出现；手表离手机稍远时要不要点「再传一次」。

## 课后 Track 2 · 手机再进得到

| # | 在哪 | 点什么 |
|---|------|--------|
| 1 | **手表** | 与 Track 1 相同：DayTap 开始、停止 |
| 2 | **iPhone DayTap** | 该条 → **分享** → **得到大脑** |
| 3 | 分享表没有得到时 | 得到大脑 → **+ → 导入音视频** → 文件 → 我的 iPhone → DayTap |
| 4 | **得到大脑** | 等转写完 → 复制文字记录 |
| 5 | **本对话** | 粘贴全文：「私教 · Track2 · 出决策卡」 |

得到 **只在 iPhone**。手表点停止不会自动进得到。

**待验证**：分享表里是否总有「得到大脑」；m4a 能否被导入；长课额度。

## Track 0 · 手机保底（表没装好时）

| 方案 | 步骤 |
|------|------|
| 有得到 | iPhone **得到大脑** 里直接开录 → 结束 → 复制文稿 → Bot |
| 无得到 | iPhone **语音备忘录** 或 **飞书妙记** 开录 → 出字 → Bot |

这是保底，和手表双轨一起留着。Track 0 用的是手机，不是去把手表语音备忘录装回来。
