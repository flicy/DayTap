## 结构拆解（背诵提示，非抄袭清单）

| 段 | 作用 | 我们可学的「型」 | 我们不抄的「料」 |
|----|------|----------------|------------------|
| 开场 | 身份钩子 | 「你已经戴着最好的…」句式 | All Day 品牌名、竞品口号 |
| 续航证明 | 可信数字 | 用自己测的一段时长/电量 | Series 11 / 12.5h / 49% |
| 多信号 | 不只录音 | 我们钉决策卡，不强调全天生物信号拼接 | stress / activity 卖点照搬 |
| 隐私 | 信任 | 本地 / 自选 API / 无自建服务器（若属实再写） | 「We don't even have servers」原文 |
| 日视图 → 搜索 | 产品动线 | 一天 → 一刻 → 可溯源 | UI 文案直译 |
| Emma 段 | 情感 demo | 用自己的真实场景（会议/决策） | Emma 恋爱剧本 |
| CTA | 商业模式 | 我们开源 + Personal Agent；收费以后另定 | one time purchase 句 |
